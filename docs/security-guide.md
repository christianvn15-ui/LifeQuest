# Security and privacy guide

The starter rules deny unrecognized paths and restrict profiles to their owner. They are a baseline, not a complete production policy. Validate every field and transition, prevent users from writing balances/roles/admin fields, and put reward grants in trusted backend transactions. Add guardian consent, age-appropriate defaults, data deletion/export, retention rules, abuse reporting, audit logging, and privacy review before handling children. Escape untrusted strings before rendering; avoid `innerHTML` with user content unless escaped. Do not put sensitive journal content in guilds or shared documents. Firebase Auth provider integrations, account recovery, App Check enforcement, and Storage paths must be configured and tested before public release.
